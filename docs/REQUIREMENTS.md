# NameCraft AI — 요구사항 명세 (REQUIREMENTS)

> NameCraft v2.1 기획서의 항목을 추적 가능한 요구사항 ID로 정리한 문서다.
> 작성: Phase 0 / 2026-11-19

## 0. 표기 규칙

- ID 형식: `REQ-<영역>-<번호>` (예: `REQ-HJ-003`)
- 우선순위: `P0`(출시 필수) / `P1`(주요 고도화) / `P2`(확장) — 기획서 §3
- Phase: 해당 요구를 구현·검증하는 기획서 §21 Phase 번호
- 결과 성격 태그(기획서 §1.2, §22.3): `fact`(법적·자료적 사실) / `calc`(결정론적 계산) / `trad`(전통 해석) / `subj`(주관·AI)
