# PROJECT_PLAN

이 문서는 NameCraft v2.1의 진행 규칙을 요약한다. 세부 요구사항은 [요구사항 문서](REQUIREMENTS.md)를 참고한다.

- `writing-block.md`는 v1.0 기획서이며 참고용(SSOT 아님).
- Phase 0~12를 순서대로 진행하며, 한 Phase 완료 전 다음 Phase의 핵심 로직을 개발하지 않는다(인터페이스 mock은 허용).
- 각 Phase: 기능 명세 → 데이터/계산 테스트 → 구현 → 통합 테스트 → 문서 갱신 → 완료 보고 → **Git 커밋 → 사용자 승인 후 다음 Phase**.
- 진행 현황: [`PHASE_STATUS.md`](PHASE_STATUS.md) · 결정: [`DECISIONS.md`](DECISIONS.md) · 요구사항: [`REQUIREMENTS.md`](REQUIREMENTS.md)
