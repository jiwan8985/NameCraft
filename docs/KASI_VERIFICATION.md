# 만세력 외부 기준값 대조 체크리스트 (Phase 3 완료 게이트)

> 기획서 §21 Phase 3 완료 게이트: **"외부 기준값 Golden Tests 일치"**.
> 엔진 값은 아래와 같고, 한국천문연구원(KASI) 천문우주정보 — 음양력·절기 조회에서 같은 값을 확인하면
> `datasets/golden-tests/saju.yaml` 해당 케이스를 다음처럼 바꾼다.
>
> ```yaml
> status: externally_verified
> verified_source: SRC-KASI-LUNAR   # 또는 SRC-KASI-TERMS
> verified_at: 2026-11-20
> ```
>
> 값이 다르면 수정하지 말고 이 문서의 '불일치' 칸에 기록한다(엔진 버그 조사 대상).
