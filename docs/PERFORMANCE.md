## 3. 해석

- 개인용 단일 사용자 기준으로 모든 화면 동작이 1초 안팎. 가장 느린 것은 ±7일 시나리오(0.9초)로 천문 계산 비용.
- 랭킹은 CPU 계산이라 동시 요청이 몰리면 순서대로 처리된다(Python GIL). 8명이 동시에 목록을 열면 1.6초 — 단일 사용자 용도에서는 수용. 다중 사용자 서비스로 확장할 때는 워커 프로세스 여러 개 또는 랭킹 결과 캐시가 필요.
- 최적화(Phase 12): 음절별 한자 후보를 한 번에 조회(획수·공식 판정 일괄 쿼리), 한 요청 안에서만 쓰는 캐시(공식 자료 갱신은 즉시 반영), 생성 결과의 한자 '제안'은 음절별 상위 12자 조합으로 제한(전체 조합은 역검색 화면), 부정 연상 비교 문자열을 한 번만 계산.
- 회귀 방지: `pytest -m perf` (테스트 DB 기준 넉넉한 예산).
